# family-skills

家庭生活后台技能包（WorkBuddy Skills），7 个技能覆盖记账、待办、健康档案、凭证、日记、读书笔记、电脑管家。

所有数据统一存在**腾讯文档**的「生活后台」共享文件夹里，全家共用一份账本和待办表，各自跟自己的智能体聊天即可写入同一处。

## 技能列表

| 技能 | 触发说法 | 功能 |
|---|---|---|
| family-ledger | 「记一笔」「花了」「这个月吃饭花了多少」 | 家庭记账，账本为腾讯文档智能表格 |
| family-todo | 「记个待办」「每周六提醒我」「这事做完了」 | 家庭待办，每天 8:00 自动下发、周日晚生成周报 |
| family-health-archive | 「存一下报告」「上次体检尿酸多少」 | 体检报告/化验单归档与解读 |
| voucher-vault | 「发票归档」「保修还有多久」 | 发票、保单、合同等凭证保险箱 |
| personal-diary | 「记一下今天」「这个月日记总结」 | 每天一篇个人日记 |
| reading-notes | 「在读《xx》」「书摘」 | 读书笔记、书单、年度阅读报告 |
| mac-butler | 「电脑体检」「磁盘满了」 | Mac 体检与清理（删除操作需确认） |

## 安装（给 tina 的说明）

1. 把 `family-skills` 克隆或下载到本地
2. 将各技能文件夹复制到 `~/.workbuddy/skills/`（用户级技能目录），保持「一个技能一个文件夹、内含 SKILL.md」的结构
3. 重启 WorkBuddy 对话，新技能即生效
4. 在 WorkBuddy 连接器中**授权腾讯文档**（数据写入依赖它）
5. 首次记账/记待办时，智能体会问「怎么称呼你？」——回答你在家庭成员名单里的称呼（如 tina），之后数据归属自动生效

## 数据约定

- 根文件夹：腾讯文档「生活后台」（子文件夹：家庭记账 / 家庭待办 / 家庭报告 / 家庭健康等）
- 家庭成员名单：`生活后台/家庭待办/家庭成员名单`（称呼 + 邮箱，新增成员加一行）
- 每日 8:00 由自动化生成「今日待办」并按人发邮件；每周日 20:00 生成家庭周报并邮件推送
- 本地不留任何数据文件，一切以腾讯文档为准
